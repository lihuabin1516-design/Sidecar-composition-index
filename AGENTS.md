# ccpanes-workflow-adapter

This repository owns a read-only composition index for existing local sidecar
artifacts. It does not own execution, permissions, evidence, completion, or
Skill promotion.

Run `pnpm run typecheck`, `pnpm run lint`, `pnpm test`, and
`pnpm run smoke:production` before handoff. Do not stage, commit, push, or
modify global configuration during ordinary development.
